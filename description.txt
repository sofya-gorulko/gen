
Для решения задания был написан код на C++.
Была создана структура для хранения информации из одного прочтения: самого генома, качества прочтения и длины участка.
Для вычисления статистики (минимум и тд) с помощью цикла перебраны все прочтения и посчитаны необходимые значения (вроде бы очевидно).
Для GC-состав посчитано общее количество G и C нуклиотидов.
Среднее значения качества на позиции 10 тоже расчитано с помощью прохождения по всем прочтениям циклом.
Тримминг со скользящим окном n и качеством q реализован со знаком <=. Сначала отсекаются все слишком короткие прочтения, затем те, у которых первые n символов качества в сумме меньше n*q. Дальше после пересчета окна и обнаружения подходящего, отрезались все символы правее самого правого символа в окне, меньшего q. В общем, все по алгоритму.
Триммин по длине 60 убирал все строки, которые строго короче 60 символов.

Отдельным сравнением решения с готовыми программами не занималась. Первые 3 пункта зашли без проблем, в 4 (тримминг) модифицировала код, пока не зайдет: свелось к перебору знаков (>, >=, ==), пока не нашлась компинация, прошедшая тесты)
Никакие специализированные библиотеки языка не использовала, только простые конструкции языка: структуры (удобно для хранения и обращения), вектор(чтобы не записывать каждый раз в файл), методы для строк (длина, подстрока, конверация строки в чило) - которые облегчили решение.
